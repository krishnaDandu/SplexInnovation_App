# SPLEX Innovation - Angular 20

Angular 20 standalone project based on the supplied working HTML prototype.

## Requirements

- **Node.js**: v18.20+, v20.x, or v22.x
- **Angular**: 20.3.30
- **TypeScript**: 5.8.0
- **npm**: Latest version

## Structure

- `src/app/header` - reusable header/navigation
- `src/app/footer` - reusable footer
- `src/app/home` - Home page
- `src/app/aboutus` - About Us page
- `src/app/services` - Services page
- `src/app/contactus` - Contact Us page
- `src/assets` - prototype images, Bootstrap and Bootstrap Icons assets
- `src/main.css` - prototype/global CSS

## Run

```powershell
npm install
npm run start
```

Open `http://localhost:4200`.
